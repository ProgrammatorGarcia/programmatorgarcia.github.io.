# Project rules

## Java brace style

Use **Allman (ANSI) brace style** whenever creating or updating Java code for this course, including examples, starter code, and solutions in assignment pages and Java source files.

- Put each opening brace on its own line after the class, method, or control-flow statement that introduces the block.
- Put each closing brace on its own line, aligned with its opening brace.
- Put `else`, `else if`, `catch`, and `finally` on a new line after the preceding closing brace, with their opening braces on the following line.
- Indent the contents of each block by four spaces.
- Show this style consistently in student-facing examples and explain it when giving formatting directions.

Example:

```java
if (answer == correctAnswer)
{
    System.out.println("Correct!");
}
else
{
    System.out.println("Try again.");
}
```
