Part 1 notes · Read before Problems 1–6

Meet the for loop

A loop repeats a block of code. A for loop is convenient when you know how many repetitions you want, or which numbers you want to visit.

Read this example before beginning. Predict what it prints, then trace the changing value of round.

for (int round = 1; round <= 3; round++)
{
    System.out.println("Practice round " + round);
}
The three parts of this loop’s header
PartWhat it does
int round = 1Start the counter at 1. This happens once.
round <= 3Check the condition before each repetition. If it is false, leave the loop.
round++Add one after the body finishes, then check the condition again.

The body prints rounds 1, 2, and 3. After the third repetition, the update makes round equal to 4. The condition is false, so there is no fourth repetition.

Keep track of what changes

CodeMeaning
count++;Add one to count. This is the same as count = count + 1;.
count--;Subtract one from count.
total = total + amount;Add amount to the old total and store the new total.
number % 2 == 0Check whether a number is even.

Where does this line belong?: Initialize a running total or score before the loop, change it inside the loop, and print the finished result after the loop. A variable created inside the loop’s braces cannot be used outside those braces.

Braces and semicolons: Keep braces around the loop body and use Allman (ANSI) style, as shown above: the opening brace goes on the next line, and the closing brace lines up with it. The two semicolons belong inside a for header. Do not put a semicolon between the closing ) and the opening {.

Part 2 notes · Read before Problems 7–9

Meet the while loop

A while loop checks a condition before each repetition. It is useful when you want to keep going until something changes, such as a user finally entering an acceptable answer. It can also count, as in this example:

int round = 1;
while (round <= 3)
{
    System.out.println("Practice round " + round);
    round++;
}

This prints the same three practice rounds as the earlier for example. Here, the counter starts before the loop, and the update is written inside the body.

  1. Set up the value the condition will check.
  2. Check the condition. If it is false, skip the body and continue after the loop.
  3. If it is true, run the body. Change the counter or read a new input so the condition can eventually become false.
  4. Return to the condition and check again.

A loop can run zero times: If the first input is already acceptable, a retry loop should skip its body. There is no need to print an error or ask again.

Avoid an endless loop: If the value in the condition never changes, the loop may never stop. For a countdown, update the counter inside the loop. For a retry prompt, read the replacement answer inside the loop. If your program runs endlessly in the terminal, press Ctrl+C, then check the condition and update.

When you compare text

Use .equals() for String contents. The operator ! means “not.” For example, !word.equals("hello") is true when word is not "hello". Capitalization matters.

Before each problem, ask yourself: What repeats? What changes? What makes this loop stop?

11. The Computer Grades Until You Say Stop

Your program does not know how many quiz scores the user wants to enter. Use a while loop to keep reading integer scores from 0 through 100. The user enters -1 to finish.

  1. Ask for the first score before the loop.
  2. For each score other than -1, add it to a running total and increase the number of scores entered by one.
  3. Ask for the next score inside the loop. Stop when the user enters -1.
  4. After the loop, print the number of scores and their total. If at least one score was entered, also print the average as a double. Otherwise, print No scores were entered. instead of calculating an average.

Assume each entry is either a score from 0 through 100 or -1; no range-validation loop is needed. A score of 0 counts as a score. The stopping value -1 does not count and must not be added to the total.

Enter a score from 0 through 100, or -1 to finish:

Two new details: A special value used to end input is called a sentinel. Also, dividing one int by another drops the fractional part. With integer variables named scoreTotal and scoreCount, use scoreTotal / (double) scoreCount to keep the decimal part. Only calculate this when scoreCount > 0. You do not need to round the average.

Finally, use if / else after the loop to handle the average or the no-scores message. Think carefully about where the next input belongs so that the sentinel is never processed as a score.

Part 4 notes · Read before Problem 13

A loop inside a loop

A nested loop is a loop inside another loop’s body. The inner loop runs all the way through for each repetition of the outer loop. Think of arranging seats: the outer loop chooses the row, and the inner loop visits the seats in that row.

Read this small example. It uses two rows and three seats per row:

for (int row = 1; row <= 2; row++)
{
    for (int seat = 1; seat <= 3; seat++)
    {
        System.out.print("(" + row + "," + seat + ") ");
    }
    System.out.println();
}

Output

(1,1) (1,2) (1,3)
(2,1) (2,2) (2,3)
  • System.out.print(...) prints without moving to a new line. The space at the end separates the seats.
  • System.out.println(); moves to a new line without printing any text. Here, it belongs after the inner loop, but inside the outer loop.
  • The inner counter starts at 1 again each time the outer loop begins a new row. For row 1, the seat values are 1, 2, 3; then row 2 gets its own seat values 1, 2, 3.
  • The inner printing statement runs 2 × 3 = 6 times in total. The new-line statement runs twice.

Before you code: Trace the example on paper. What would happen if you moved System.out.println(); inside the inner loop? In the staircase below, each row needs a different number of symbols, so the inner loop’s endpoint will depend on the current row.

13. The Penguins Build a Staircase

The penguins want a staircase made of asterisks. Ask the user for an integer height from 1 through 8. Use a while loop to reject heights outside that range and ask again.

Once the height is accepted, use nested for loops to print a left-aligned staircase:

  1. The outer loop creates one row at a time, from row 1 through the chosen height.
  2. The inner loop prints one * at a time. Row 1 has one star, row 2 has two, and so on. Do not put spaces between the stars.
  3. Move to a new line only after a complete row has been printed.
  4. Count every star as it is printed. After the entire staircase, print the total number of stars.

Use a single System.out.print("*"); statement inside the inner loop. Do not write separate printing statements for each row, use String.repeat(), or use a formula to calculate the star total. Finish input validation before starting the two drawing loops.

***

Build it in stages: First, adapt Problem 8 to reject a value that is less than 1 or greater than 8; || means “or.” Then use the seat example to print a small rectangle. For the staircase, change the inner loop’s endpoint so it uses the current row number. Finally, set a star counter to zero before the outer loop and increase it inside the inner loop, alongside the printing statement.

In one run, enter -2, then 9, then 3: reject the first two entries, then print three rows with 6 stars total. Explain why the inner loop prints more stars on each new row.
